# DraftBoard

DraftBoard is a web application that allows you to draft a custom board for the game [DraftoutMC](https://draftoutmc.com) with up to 4 players. The goal is to replicate the in-game experience with a web-based system that allows more flexibility and features for a custom Lobby game with friends.

For example if you want to play a 1v1v1v1 lockout game and also want to draft the board instead of fully randomizing the board, you can do it here.

## Features
- Draft with up to 4 players
- Custom board size
- Custom picking time limit
- Real-time updates
